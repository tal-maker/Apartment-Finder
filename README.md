# 🏠 מוצא דירות ת״א

אפליקציית ווב שמחפשת דירות להשכרה בתל אביב-יפו ב**יד2**, ב**קבוצות פייסבוק** וב**ערוצים/קבוצות טלגרם**, מסננת לפי הקריטריונים שלכם, ושולחת **הודעה בטלגרם** (או בוואטסאפ) ברגע שעולה דירה חדשה שמתאימה.

## מה יש בה

- **סריקה כל 5 דקות** של כל המקורות הפעילים (ניתן לשינוי ב־`SCAN_INTERVAL_MINUTES`).
- **פילטרים**: אזורים ושכונות (8 אזורים, ~50 שכונות), טווח מחיר, מספר חדרים, גודל, קומה, מצב הדירה (חדשה / משופצת / שמורה / דורשת שיפוץ), טווח תאריכי כניסה, ממ״ד, חניה, מחסן, מעלית, מרפסת, ריהוט, חיות מחמד (לכל אחד: לא משנה / חובה / בלי), תיווך / ללא תיווך, סוג מודעה (השכרה / שותפים / סאבלט), מקורות, מילות מפתח לכלול ולהחריג.
- **חיפושים שמורים**: כל חיפוש פעיל נבדק בכל סריקה, ודירה חדשה שמתאימה לו נשלחת אליכם בהודעה. אפשר כמה חיפושים במקביל (למשל אחד לכם ואחד לחבר).
- **ניתוח מודעות טקסט**: פוסטים בפייסבוק ובטלגרם מנותחים אוטומטית (מחיר, חדרים, שכונה, ממ״ד, חניה, תיווך, תאריך כניסה…). מסננים החוצה פוסטים של "מחפש/ת דירה", מכירה ודירות בערים אחרות. אופציונלי: עם `ANTHROPIC_API_KEY` ‏Claude קורא את הפוסטים והדיוק עולה משמעותית.
- **מודעות חסרות פרטים**: פוסט שלא מציין למשל חניה לא נפסל – הוא מופיע עם ❔ "לא צוין". מי שרוצה רק מודעות מפורטות מסמן "הצג רק מודעות שמציינות במפורש".
- **בלי כפילויות**: אותה דירה שפורסמה ביד2 וגם בפייסבוק (לפי טלפון / כתובת+מחיר) תשלח פעם אחת.
- מועדפים ⭐, הסתרת מודעות, מיון לפי מחיר, ממשק בעברית שמתאים גם לנייד.

## הפעלה מהירה (מצב דמו)

```bash
npm install
npm run dev     # מקורות מדומים (כדי לראות הודעות בלוג: NOTIFY_PROVIDER=console ב־.env)
# http://localhost:3000
npm test
```

## הפעלה אמיתית

1. `cp .env.example .env` ומלאו את ההגדרות (פירוט למטה).
2. `npm install && npm start`
3. בלשונית **מקורות והגדרות**: הפעילו את המקורות והוסיפו ערוצי טלגרם וקבוצות פייסבוק.
4. בלשונית **דירות**: הגדירו סינון ← **שמור כחיפוש עם התראות** ← בלשונית החיפושים לחצו **שלח הודעת בדיקה**.

הסריקה הראשונה של כל מקור רק "לומדת" את מה שכבר מפורסם, בלי לשלוח התראות (אחרת תקבלו מאות הודעות). מהסריקה השנייה – רק דירות חדשות.

האפליקציה צריכה לרוץ ברציפות (שרת VPS, Railway/Fly.io/Render עם דיסק קבוע, או מחשב בבית). Docker:

```bash
docker build -t apartment-finder .
docker run -d --restart unless-stopped -p 3000:3000 --env-file .env -v $PWD/data:/app/data apartment-finder
```

אם האפליקציה פתוחה לאינטרנט – הגדירו `APP_USER` ו־`APP_PASSWORD`.

## התראות

בוחרים ספק ב־`NOTIFY_PROVIDER`.

### בוט טלגרם (מומלץ, חינם)
1. בטלגרם פותחים שיחה עם **@BotFather**, שולחים `/newbot`, בוחרים שם ושם משתמש (חייב להסתיים ב־`bot`), ומקבלים **טוקן**.
2. ב־`.env`: `NOTIFY_PROVIDER=telegram` ו־`TELEGRAM_BOT_TOKEN=<הטוקן>`.
3. מריצים `npm run telegram:bot-setup`, ובזמן שהוא מחכה פותחים את הבוט בטלגרם ולוחצים **Start**. הסקריפט שולח הודעת אישור ומדפיס שורת `TELEGRAM_ALERT_CHAT_IDS=...` – מעתיקים אותה ל־`.env`.
4. מפעילים מחדש את האפליקציה.

כדי שכמה אנשים יקבלו התראות: מוסיפים את הבוט לקבוצת טלגרם, כותבים בה הודעה בזמן שהסקריפט רץ, ומשתמשים במזהה הקבוצה (מספר שלילי). אפשר גם כמה מזהים מופרדים בפסיק.

### וואטסאפ

| ספק | מתאים ל | הגדרה |
| --- | --- | --- |
| `callmebot` | חינם, הודעות למספר שלכם (לפעמים אין מקום פנוי לנרשמים חדשים) | לפי [ההוראות של CallMeBot](https://www.callmebot.com/blog/free-api-whatsapp-messages/) שולחים להם הודעת הרשאה בוואטסאפ ומקבלים apikey, והגדירו `CALLMEBOT_RECIPIENTS=972501234567:apikey` (כמה נמענים מופרדים בפסיק) |
| `twilio` | יציב, בתשלום | `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_WHATSAPP_FROM`, `TWILIO_WHATSAPP_TO`. ב־sandbox צריך קודם לשלוח את קוד ההצטרפות למספר של Twilio |
| `meta` | בוט רשמי של WhatsApp Business (Cloud API) | `META_WA_TOKEN`, `META_WA_PHONE_NUMBER_ID`, `META_WA_TO`. הודעה חופשית מגיעה רק אם כתבתם לבוט ב־24 השעות האחרונות; אחרת צריך תבנית מאושרת עם משתנה אחד ב־`META_WA_TEMPLATE` |

עד `MAX_ALERTS_PER_SCAN` הודעות בכל סריקה (ברירת מחדל 10); השאר מסוכמות בהודעה אחת.

## מקורות

### יד2
עובד בלי הגדרות. קורא את שני עמודי התוצאות האחרונים של השכרה בתל אביב (`YAD2_PAGES`) ונכנס לכל מודעה חדשה כדי לקרוא ממ״ד, חניה, מחסן, תאריך כניסה ותיאור.

ליד2 יש הגנה נגד בוטים. כשהיא חוסמת, הכלי עובר אוטומטית לסריקה דרך דפדפן אמיתי ברקע (ב־Windows – Microsoft Edge שכבר מותקן; ב־Mac/Linux – `BROWSER_CHANNEL=chrome` או `npx playwright-core install chromium`). הדפדפן שומר עוגיות בתיקייה `data/browser-profile`. אם עדיין מופיעה שגיאת captcha:
1. עוצרים את האפליקציה (Ctrl+C).
2. `npm run yad2:unblock` – נפתח חלון של יד2; פותרים את ה־captcha עד שרואים דירות, ולוחצים Enter בטרמינל.
3. מפעילים שוב `npm start`.

אם ה־captcha חוזר כל הזמן: מגדירים `BROWSER_HEADLESS=0` ב־`.env`. אז נפתח חלון דפדפן גלוי של יד2 שנשאר פתוח בין הסריקות (אפשר למזער אותו, לא לסגור). כשמופיע בו captcha, פותרים אותו בחלון והסריקה ממשיכה. אפשר גם להגדיל את `SCAN_INTERVAL_MINUTES`.

### טלגרם
- **ערוצים ציבוריים** – רק מוסיפים את שם הערוץ או קישור `t.me/...` בהגדרות. אין צורך בחשבון.
- **קבוצות** (ופרטיים) – צריך להתחבר עם חשבון טלגרם שחבר בקבוצות:
  1. צרו אפליקציה ב־https://my.telegram.org/apps והגדירו `TELEGRAM_API_ID` ו־`TELEGRAM_API_HASH`.
  2. `npm run telegram:login` – מזינים טלפון וקוד, ומקבלים `TELEGRAM_SESSION` להעתיק ל־`.env`. (שמרו אותו בסוד – הוא נותן גישה לחשבון.)

### קבוצות פייסבוק
לפייסבוק אין API לקריאת קבוצות, לכן האפליקציה פותחת את הקבוצות בדפדפן שלה (אותו דפדפן שמשמש ליד2) עם החשבון שלכם, וקוראת את הפוסטים האחרונים.
1. עוצרים את האפליקציה (Ctrl+C) ומריצים `npm run facebook:login` – נפתח חלון דפדפן; מתחברים לפייסבוק (כולל אימות דו־שלבי אם יש) ולוחצים Enter בטרמינל. ההתחברות נשמרת בתיקייה `data/browser-profile`.
2. מפעילים שוב `npm start`.
3. בלשונית **מקורות והגדרות** מסמנים "קבוצות פייסבוק" ומוסיפים קישורי קבוצות (שורה לכל קבוצה). החשבון צריך להיות חבר בהן.

⚠️ גלישה אוטומטית מנוגדת לתנאי השימוש של פייסבוק, ופייסבוק עלולה לבקש אימות או לחסום. עדיף חשבון משני, ולא יותר מ־5–10 קבוצות. כשפייסבוק מבקש להתחבר מחדש, מופיעה שגיאה בלשונית הסטטוס – חוזרים על שלב 1.

## ניתוח עם Claude (אופציונלי)

עם `ANTHROPIC_API_KEY` כל פוסט **חדש** מפייסבוק/טלגרם נשלח פעם אחת ל־Claude שמחלץ את הפרטים בצורה מובנית (הניתוח לפי ביטויים משמש כגיבוי). ברירת המחדל היא `claude-opus-5-5` ב־effort נמוך; אפשר להחליף מודל ב־`ANTHROPIC_MODEL` (למשל `claude-haiku-5-5` – זול בהרבה). מודעות יד2 לא נשלחות – הן כבר מובנות.

## מבנה הקוד

- `server/scanner.js` – לולאת הסריקה: מקורות ← ניתוח ← שמירה ← התאמה לחיפושים ← התראה.
- `server/sources/` – יד2 (`__NEXT_DATA__` של Next.js), טלגרם (t.me/s או MTProto), פייסבוק (Playwright), מקורות דמו.
- `server/parse/text.js` – חילוץ פרטים מטקסט חופשי בעברית; `server/parse/llm.js` – חילוץ עם Claude.
- `server/neighborhoods.js` – אזורים ושכונות של ת״א וזיהוי שלהם בטקסט.
- `server/match.js` – לוגיקת הסינון; `server/notify/notifier.js` – ספקי ההתראות (בוט טלגרם, וואטסאפ) ועיצוב ההודעה.
- `server/db.js` – SQLite מובנה של Node (`node:sqlite`), נשמר ב־`data/apartments.db`.
- `public/` – הממשק (JS נקי, בלי build).

דורש Node 22.13 ומעלה.

## מגבלות ידועות

- הסורקים בנויים לפי מבנה הדפים של יד2, t.me ופייסבוק. כשהאתרים משנים מבנה, צריך לעדכן את הסורק – השגיאה תופיע בלשונית "מקורות והגדרות".
- זיהוי לפי ביטויים בפוסטים חופשיים לא מושלם (למשל כתובות מנוסחות בצורה חריגה). Claude משפר את זה מאוד.
- שמירת היסטוריה: 45 יום (`KEEP_DAYS`), מלבד מועדפים.
